# SCN-025: Fail Safely on Provider Outage

- Requirement: [REQ-016](../../doc/requirements/functional-requirements.md#req-016-handle-dependency-failure-safely)
- Feature: Human review, conflicts, and failures
- Priority: Must
- Status: Planned

```gherkin
@REQ-016 @must
Scenario: Fail safely on provider outage
  Given the configured live provider is unavailable
  When a ticket requires provider processing
  Then no customer answer is drafted from implicit model memory
  And a typed provider error requires human review
```
