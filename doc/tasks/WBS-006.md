# WBS-006: Prepare Engineering Foundation

- Status: In progress
- Owner: Engineer
- Governing source: [Master prompt](../master-prompt.md)
- Depends on: [WBS-005](WBS-005.md)

## Objective

Make the Python 3.12+ MVP installable, testable, lintable, and runnable through documented local commands before adding the full schema and CLI boundary.

## Prompt

Create the minimum reproducible Python project configuration for the package under `src/support_copilot`. Preserve the existing Behave and pytest workflows, configure Ruff, avoid production infrastructure, and verify all currently implemented scenarios.

## Functional limits

- Keep the current package layout and deterministic offline behavior.
- Configure project metadata, supported Python version, package discovery, test paths, and lint rules.
- Do not add the real CLI or Pydantic output schema; those begin in increment 4 / SCN-004.

## Non-functional limits

- Python baseline: 3.12 or newer.
- Tests must remain credential-free and deterministic.
- Developer commands must work from the repository root.
- Configuration must not imply that unimplemented scenarios or production deployment are complete.

## Acceptance checklist

- [x] `pyproject.toml` defines build and package metadata.
- [x] Pytest discovers `tests/` and imports from `src/`.
- [x] Ruff targets Python 3.12 and the project source/test files.
- [x] Behave remains the executable BDD runner.
- [ ] A real CLI entry point and Pydantic contracts are implemented in the next domain increment.
- [ ] CI executes lint, unit, BDD, Gherkin, and architecture-document validation.
