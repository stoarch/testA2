## Limits

- Phase 1 excludes queues, microservices, Kubernetes, vector databases, and complex UI.
- Planned architecture is not completion evidence; only executed tests change an implementation item to Done.
- Customer transmission is outside the MVP.

## Definition of done

Every increment has linked requirements/scenarios, a recorded red-green-refactor cycle, passing regression tests, updated traceability, and honest remaining limitations.
