## Current increment

WBS-007.018 / SCN-018 will process a ticket through the Phase 1 CLI and display the structured classification, answer outcome, citations, and review decision.

### Limits

- Extend the existing credential-free CLI rather than introducing a web framework.
- Return the validated auditable result contract for a deterministic offline ticket journey.
- Display classification, drafted or abstained status, citations, and the human-review decision as JSON.
- Do not add automatic customer transmission, live-provider calls, or persistent audit storage.

### Verification plan

- BDD: SCN-018 minimal-interface submission and structured display behavior.
- TDD: CLI request mapping and output-contract selection for the bounded offline journey.
- Integration: classifier, deterministic outcome, and audit-result composition reach one application service.
- E2E: subprocess CLI invocation returns schema-valid JSON with classification, outcome, citations, and review decision.
