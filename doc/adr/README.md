## Lifecycle

Use one of these statuses: `Proposed`, `Accepted`, `Rejected`, `Deprecated`, or `Superseded by ADR-####`.

1. Copy [the template](0000-template.md) and assign the next four-digit number.
2. Describe the decision context and constraints without assuming the outcome.
3. Document considered options and meaningful tradeoffs.
4. Add links to related `REQ-###` and `WBS-###` items.
5. Never rewrite an accepted decision to change history; supersede it with a new ADR.
