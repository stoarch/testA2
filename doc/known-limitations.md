# Known Limitations

- Only SCN-001 and SCN-002 have executable step definitions and passing production behavior.
- Category recognition currently supports only the case-insensitive marker `withdraw`.
- Pydantic contracts, CLI, persisted KB snapshots, retrieval, citations, drafting, policy gates, routing, provider adapters, integration tests, and E2E tests are not implemented.
- The 30-ticket evaluation dataset and metrics report do not yet exist.
- The business case contains formulas and placeholders, not measured savings or a justified deployment recommendation.
- PlantUML sources are present, but automated rendering is not yet a CI gate.
- No Git repository/commit evidence or repository link is currently available.
- Offline fixture, rules-only, and live-provider modes are designed but not yet executable.
